Conditionals — If, Would, Would Have

Reference

The four conditionals

Zero — always true

If + present simple, present simple

If you heat water to 100°C, it boils.

Facts, rules, habits. if ≈ when.

First — real future

If + present simple, will / won’t + verb (also can, may, should, imperative)

If it rains tomorrow, we will cancel the picnic.

Something that may really happen. Never will after if.

Second — unreal present

If + past simple, would / wouldn’t + verb

If I had more time, I would learn Italian. · If I were you, I’d wait.

Imaginary or unlikely now; advice with If I were you…

Third — unreal past

If + past perfect, would have + past participle

If she had left earlier, she would have caught the train.

Regrets and criticism about the past. It did not happen.

Word order

If it rains, we’ll stay in. = We’ll stay in if it rains.

No comma when the if-clause comes second.
